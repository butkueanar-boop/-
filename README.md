# MineTool Manager

Уурхайн агуулахын багаж хэрэгслийн бүртгэл, олголт, буцаалтын интерфэйс. Одоогийн хувилбар нь бүх дэлгэцэд ижил жишээ өгөгдөл ашигладаг локал демо бөгөөд сервер эсвэл уурхайн мэдээллийн сантай холбогдоогүй. Демо өгөгдөл дэмжигдсэн хөтөчид `localStorage`-оор хадгалагдана.

## Хөгжүүлэлт

```bash
npm install
npm run dev
```

TypeScript шалгах: `npm run typecheck`

Үйлдвэрлэлийн build: `npm run build`

Камер уншигч QR, Code 128/39/93, Codabar, EAN-13/8, UPC-A/E, ITF, Data Matrix, Aztec, PDF417 форматыг дэмжинэ. Камерын зөвшөөрөл болон HTTPS (эсвэл localhost) шаардлагатай; төхөөрөмж, хөтчийн дэмжлэгээс шалтгаалан зарим формат уншигдахгүй байж болно.

## Багажийн QR код ба шошго

Багаж шинээр бүртгэхэд `TOOL-0001` хэлбэрийн тогтмол дугаар автоматаар үүсэж, localStorage дахь багажийн бүртгэлд хадгалагдана. Өмнөх бүртгэлүүдэд давтагдашгүй QR дугаарыг аажмаар нөхөж олгох бөгөөд нэр, төлөв эсвэл ангиллыг засахад дугаар өөрчлөгдөхгүй. QR-д зөвхөн энэ тогтмол дугаар кодлогдоно; ажилтны мэдээлэл болон өөрчлөгдөх мэдээлэл орохгүй.

Бүртгэлийн жагсаалтын багажийн нэр дээр дарж QR кодыг харах, PNG татах, нэг шошго хэвлэх боломжтой. **Шошго хэвлэх** цэсээр хэд хэдэн багаж сонгон A4 хуудсанд хэвлэнэ. Хэвлэхийн өмнө хөтчийн print preview-д хуудасны хэмжээ, scaling болон шошгоны байрлалыг шалгаарай. Шошго нь QR, багажийн код, нэр болон “БҮРТГЭЛТЭЙ БАГАЖ” гэсэн бичвэртэй.

QR бүртгэл одоогоор зөвхөн тухайн төхөөрөмжийн локал демо өгөгдөлд хадгалагдана; төв серверт бүртгэгдээгүй, бусад төхөөрөмжтэй автоматаар хуваалцахгүй. QR-г MineTool Manager-ийн **Багаж олгох** эсвэл **Багаж буцаах** хэсгийн камераар уншуулж тухайн төхөөрөмжийн бүртгэлтэй тулгана. Android дээр сайтыг HTTPS хаягаар нээж камерын зөвшөөрөл өгнө (HTTP LAN хаяг камерын зөвшөөрөлд хангалтгүй байж болно). Аппликейшн дотроо шинэ багаж бүртгэх эсвэл демо хэрэгслүүдийн нэгийн QR шошгыг нээгээд, **Багаж олгох** / **Багаж буцаах** хуудаснаас камераар уншуулна. Тухайн Android хөтөч өөрийн локал өгөгдөлтэй тул шошго үүсгэсэн утасны бүртгэл автоматаар Android төхөөрөмжид дамжихгүй. Android камерын апп-аар QR скан хийхэд `TOOL-####` дугаар харагдах бөгөөд багажийн мэдээллийг авахын тулд MineTool Manager дотор уншуулна.

Багажийн зураг JPEG, PNG, WebP форматаар, нэг файлд 5 МБ хүртэл хэмжээгээр хүлээн авна. Эх зургийг IndexedDB-д, жагсаалтын WebP жижиг дүрсийг тусад нь хадгалдаг; localStorage-д зөвхөн зургийн түлхүүр бичигдэнэ. Зураг нь зөвхөн тухайн хөтөч, төхөөрөмж дээр үлдэх бөгөөд серверт илгээгдэхгүй, нөөцлөгдөхгүй. Хөтчийн хадгалалт цэвэрлэгдсэн эсвэл төхөөрөмж солигдсон бол зураг дахин боломжгүй.

PWA суурь манифест, аппликейшний дүрс болон өнгөний мета өгөгдөл нэмэгдсэн. Service worker, офлайн камер, backend холболт болон серверийн хадгалалт хэрэгжээгүй. Демо үйлдлүүд сервер рүү илгээгдэхгүй.
